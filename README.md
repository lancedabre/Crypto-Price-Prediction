# Crypto Price Prediction

This project contains an NLP pipeline for scraping cryptocurrency news headlines, calculating sentiment scores, and aggregating them by day.

## Project structure

- `app.py` - entry point for running the pipeline
- `nlp_pipeline.py` - NLP pipeline module for news sentiment aggregation
- `ml_pipeline.py` - placeholder for model training and prediction
- `models/` - saved model artifacts
- `requirements.txt` - Python dependencies

## Usage

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the NLP pipeline:

```bash
python app.py
```
